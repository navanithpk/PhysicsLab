// Why PhysicsLab
Built to make concepts click.
🔬
Real physics, not approximations
Every simulation uses actual mathematical models — probabilistic decay, SUVAT kinematics, Bayesian inference, genuine isotope data.
📱
Works everywhere
Pure HTML, CSS and JavaScript. No framework, no server, no account. Load on a phone, a projector, or a laptop — offline too.
🛠
Open and extensible
Each simulator is a single self-contained file. Fork it, remix it, deploy it on GitHub Pages in under a minute.
