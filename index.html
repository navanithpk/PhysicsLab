// Why PhysicsLab

Designed for the exam, not the textbook.

📐
Syllabus-mapped
Every widget maps to specific Cambridge IGCSE 0625 and IBDP Physics topics, with syllabus point references shown on each card.
🔬
Real data, not estimates
Isotope half-lives and properties come from the nuclear data library. Simulations use probabilistic decay mathematics, not animations.
📱
Works anywhere
Pure HTML, CSS and JavaScript — no framework, no server. Works in any modern browser, on phones, tablets, and projectors.
